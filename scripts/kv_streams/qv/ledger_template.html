Handoff Ledger

Offline run of the Q/V judge on the base model's Craftax handoffs. Each game was replayed from its seed to recover the true state and full map at every reset; the judge scored the state (V), the possible gain (G*) and the summary's flaws (D). A segment's reward is how much it raised Q.

How the numbers are built

V_k = B_k + P_k state: banked achievement points + position (tool 0-4, ready 0-3, safe 0-2, near 0-1) G*_k = min(10, Σ_j p_j · points_j + expected position gain) expected gain of a good agent before the next reset D_k = 1 − Π_flaws (1 − w) summary damage: false fact .3 · made-up rule .2 · next goal wrong .4 / vague .1 · location .15 · impossible step .2 · urgent need ignored .3 · dropped fact .1 (max 3) Q_k = V_k + G*_k · (1 − D_k) game start and end: Q = V R_t = clip((Q_{t+1} − Q_t) / max(G*_t, 1), −1, 1) segment t runs from reset t to reset t+1
